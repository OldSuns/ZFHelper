## Highlights

- The Android Live Update capsule now shows the course name in the icon slot and the location on the right, instead of an icon-only layout.
- Added a capsule style setting to choose between the new course-name-plus-location layout and the previous course-name-only layout; switching it republishes active reminders immediately.
- Reorganized the Live Updates settings page into reminders, display style and preview, system permissions, and current status sections.

## Installation

- Android: download the APK and install it on an Android 13+ device.
- Windows: download the ZIP, extract the complete directory, and run `zfhelper.exe`.
