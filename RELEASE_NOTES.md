## Highlights

- Fixed Zhengfang timetable term recognition: the term list keeps recent years near the school's current term, and the timetable picker defaults to the school's current year and semester.
- Added support for Zhengfang schools that log in with plaintext passwords (no RSA) and expose the student identity from the authenticated home page.
- Courses now clearly report when the school is outside the selection period instead of failing silently.

## Installation

- Android: download the APK and install it on an Android 13+ device.
- Windows: download the ZIP, extract the complete directory, and run `zfhelper.exe`.
