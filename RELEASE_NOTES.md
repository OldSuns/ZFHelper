## Highlights

- Fixed update checks remaining on “Preparing to check for updates…” after a newer release was found.
- Moved the Timetable/Agenda switcher into the timetable toolbar and added compact controls for narrow and large-text layouts.
- Made the saved term picker open without an unnecessary network refresh, with an explicit refresh action and a collapsed manual term form.

## Installation

- Android: download the APK and install it on an Android 13+ device.
- Windows: download the ZIP, extract the complete directory, and run `zfhelper.exe`.
