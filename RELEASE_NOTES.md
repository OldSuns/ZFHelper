# Highlights

- Introduced the LXY edition, displayed as 流星雨课表, based on ZFHelper 0.2.3.
- Added an independent LXY update channel. Update checks, release notes, and APK downloads stay within LXY; ordinary ZFHelper releases are excluded.
- Retained the Android application identity and existing local data locations so the signed APK can replace the ordinary edition without resetting accounts, timetables, grades, or settings.

## Installation

- Android 13+: download the LXY APK and install it over the ordinary edition. The signing certificate must match and the build number must be higher than the installed application's; do not uninstall the existing app first.
- Later LXY versions are available through the application's update checker. This channel distributes APKs only.
