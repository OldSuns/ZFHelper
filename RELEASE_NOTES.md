# Highlights

- Fixed the app, Android launch screen, and home-screen widget to the dark Catppuccin Mocha theme, including when upgrading from a saved light/system appearance.
- Added an editable 成都银杏酒店管理学院 school option while retaining custom school names and academic-system addresses.
- Added the optional 宜宾校区 13-period timetable for that school's academic-system address. Select the campus, apply its preset, review the undoable draft, and save; other campuses keep their existing times. The fifth period remains 12:00–13:00.
- Removed the appearance menu and shortened desktop-widget settings to status, display controls, and actions.

## Installation

- Android 13+: install the signed APK over the previous signed LXY edition, or use its in-app update checker. Version 0.2.4 uses Android build number 15 and preserves the existing application identity and local data locations; do not uninstall the existing app first.
- LXY checks only LXY releases. This channel distributes signed APKs only and does not take GitHub's Latest designation.
