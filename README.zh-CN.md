# ZFHelper

[English](README.md) | [简体中文](README.zh-CN.md)

面向新正方教务系统的 Flutter/Dart 客户端，Android 优先，同时支持 Windows。

## 项目状态

当前版本为 **0.1.0+1**，仍在开发中。应用界面目前使用简体中文；英文文档不代表已经提供英文界面。学校兼容性与正式发布条件仍需真实学校和设备验收。

## 功能

| 页面 | 当前能力 |
| --- | --- |
| 课表 | 周课表与按日期查看的日程、学期/周次选择、搜索、课程详情、本地编辑及离线查看 |
| 选课 | 可选课程、教学班详情与余量、已选记录、立即选课、手动启动捡漏及操作记录 |
| 成绩 | 获取已公布成绩，本地按学期/搜索/排序/筛选查看、详情、参考统计及离线保存 |
| 设置 | 学校与账号、外观、课表导入与管理、校历/作息、Android 小组件管理及本地数据信息 |

用户自行填写学校名称与教务网址，不预置学校。支持多个学校与账号；保存会话与可选的密码保存是独立选择。

在 **设置 > 课表** 导入或更新课表。在校历设置中填写第一教学周的周一，或按当前教学周校正；不会按月份猜测教学日期。可按校区生成上午、下午、晚上的作息，预览、微调后显式保存。

日程合并展示课程与本地个人安排，支持待办、活动、考试、作业及其他分类。个人日程按账号隔离，独立于学期保存。

成功保存的数据保留到主动更新或清除，更新失败保留旧数据。退出登录保留离线数据，移除账号或学校则清理其本机数据。选课成功以学校已选记录为据，不以 HTTP 响应成功代替。

外观支持跟随系统及持久保存的浅色/深色模式，使用 Catppuccin Latte/Mocha 配色。

## 平台

| 平台 | 运行方式与平台能力 |
| --- | --- |
| Android 13+（API 33） | 自适应界面、前台服务支撑的捡漏，以及离线桌面课表小组件 |
| Windows | 侧栏与分栏布局；选课操作依赖应用进程持续运行；不提供 Android 小组件 |

Android 后台运行受通知权限、服务时限与省电策略限制。小组件更新不等于准点课程提醒。重启后，中断操作需要手动继续或核实结果。

## 开始使用

应用要求 Flutter **>=3.47.4**、Dart **^3.13.3**，以 [pubspec.yaml](pubspec.yaml) 为准。平台工具链要求见 [开发说明](docs/development.md)。

在仓库根目录执行：

```powershell
flutter pub get
flutter devices
flutter run -d windows
```

Android 使用 `flutter run -d <device-id>`，设备 ID 来自 `flutter devices`。Windows 网页登录需要 WebView2 Runtime。

## 限制

- 不保证兼容所有学校分支；真实学校的登录、课表、成绩与选课结果仍需对照验收。
- 检查更新和关于弹窗中的 GitHub 按钮目前是禁用占位项。
- ICS 导出、学校考试安排获取、系统课程提醒、Live Updates 和情侣课表尚未实现；手动录入考试日程已支持。
- 定时抢课、云端代抢、自动退课及跨设备同步不在当前范围内。
- 真实设备的后台行为、正式签名与升级流程仍需验收。本地构建和构造数据检查不能证明这些结果。
