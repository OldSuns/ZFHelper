# 流星雨课表（LXY）

[English](README.md) | [简体中文](README.zh-CN.md)

ZFHelper 的 LXY Android 定制版，面向新正方教务系统，使用 Flutter/Dart 开发。本分支只发布 APK，面向一位指定用户使用。

## 项目状态

LXY 版本为 **0.2.4+15**，基于普通版 ZFHelper 0.2.3。界面使用简体中文。PR 和分支推送只运行质量检查，不打包 APK；`LXY` 上的 `lxy-vX.Y.Z` 标签通过检查后发布签名 APK 和校验文件，不占用 GitHub 的 Latest。通用改动可以从 `dev` 分别通过 PR 进入 `main` 和 `LXY`。学校兼容性和签名覆盖升级仍需真实学校及设备验收。

首次使用时下载 LXY APK，直接覆盖安装普通版，不要先卸载。应用 ID 和本地存储保持兼容；签名证书必须相同，构建号必须更高。后续应用内更新只接收 LXY 版本。发布内容的可见性沿用仓库设置。发布与迁移要求见[开发说明](docs/development.md#lxy-apk-releases-and-installation)。

## 功能

| 页面 | 当前能力 |
| --- | --- |
| 课表 | 周课表与按日期查看的日程、学期/周次选择、搜索、课程详情、本地编辑及离线查看 |
| 选课 | 可选课程、教学班详情与余量、已选记录、立即选课、手动启动捡漏及操作记录 |
| 成绩 | 获取已公布成绩，本地按学期/搜索/排序/筛选查看、详情、参考统计及离线保存 |
| 设置 | 学校与账号、课表导入与管理、校历/作息、Android 小组件管理及本地数据信息 |

LXY 提供可编辑的“成都银杏酒店管理学院”学校选项，同时支持自定义学校名称与教务网址。使用该校教务地址时，可在“设置 → 课表 → 校历与作息”中选择“宜宾校区”，手动套用内置的 13 节作息，检查预览后保存；已有作息不会被自动覆盖。支持多个学校与账号；保存会话与可选的密码保存是独立选择。

在 **设置 > 课表** 导入或更新课表。在校历设置中填写第一教学周的周一，或按当前教学周校正；不会按月份猜测教学日期。可按校区生成上午、下午、晚上的作息，预览、微调后显式保存。

日程合并展示课程与本地个人安排，支持待办、活动、考试、作业及其他分类。个人日程按账号隔离，独立于学期保存。

成功保存的数据保留到主动更新或清除，更新失败保留旧数据。退出登录保留离线数据，移除账号或学校则清理其本机数据。选课成功以学校已选记录为据，不以 HTTP 响应成功代替。

应用、Android 启动画面和桌面小组件始终使用 Catppuccin Mocha 深色主题，从保存了浅色或跟随系统设置的版本升级后也保持深色。

## 平台

| 平台 | 运行方式与平台能力 |
| --- | --- |
| Android 13+（API 33） | 自适应界面、前台服务支撑的捡漏，以及离线桌面课表小组件 |
| Windows（仅保留上游源码） | 保留共享实现；LXY 不构建或发布 Windows 安装包 |

Android 后台运行受通知权限、服务时限与省电策略限制。小组件更新不等于准点课程提醒。重启后，中断操作需要手动继续或核实结果。

## 开始使用

应用要求 Flutter **>=3.47.4**、Dart **^3.13.3**，以 [pubspec.yaml](pubspec.yaml) 为准。平台工具链要求见 [开发说明](docs/development.md)。

在仓库根目录执行：

```powershell
flutter pub get
flutter devices
flutter run -d <device-id>
```

Android 使用 `flutter run -d <device-id>`，设备 ID 来自 `flutter devices`。Windows 网页登录需要 WebView2 Runtime。

## 限制

- 不保证兼容所有学校分支；真实学校的登录、课表、成绩与选课结果仍需对照验收。
- LXY 只检查已发布的 `lxy-vX.Y.Z` 版本，读取本通道更新说明和对应 APK，排除普通版及预发布版本。普通版继续使用自己的稳定更新通道。
- ICS 导出、学校考试安排获取、系统课程提醒和情侣课表尚未实现；手动录入考试日程已支持。
- 定时抢课、云端代抢、自动退课及跨设备同步不在当前范围内。
- 真实设备的后台行为、正式签名安装与升级流程仍需验收。GitHub CI 和未签名发布包不能证明这些结果。
